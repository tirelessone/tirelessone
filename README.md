# Hi, I'm Jiahui Lu 👋

🎓 M.S. student in **Computer Science and Technology** at the University of Electronic Science and Technology of China (UESTC).

🤖 I focus on **LLM Agents, Multi-Agent Systems, RAG, and AI Application Engineering**, with particular interest in building reliable and controllable agent systems.

## 🔭 What I'm working on

- **LLM Agent Engineering** — tool calling, agent runtime, context management, task recovery, and long-horizon execution
- **Multi-Agent Systems** — agent orchestration, role specialization, context isolation, and collaborative reasoning
- **RAG & Knowledge Systems** — retrieval under noisy evidence, knowledge grounding, and context optimization
- **LLM Self-Correction** — improving the reliability of tool-interactive reasoning and correction

## 🚀 Selected Projects

- **ProcureAI**

- **College Application Multi-Agent System**  
  A multi-agent system for intelligent university and major recommendation, combining user profiling, information retrieval, reasoning, and recommendation.

- **408 Question Practice App**
